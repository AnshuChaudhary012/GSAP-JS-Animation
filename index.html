A beginner-friendly guide

Learn GSAP step by step

Read each level from top to bottom. Try the controls, scroll through the demos, and look at script.js to see how they work.

LEVEL 1

The first animations

A tween is one animation from a starting state to an ending state.

gsap.to()

Animate to new values. The box moves right and returns.

gsap.from()

Start with the values you give, then animate to normal.

gsap.fromTo()

Set both the start and end values yourself.

LEVEL 2

Animation controls

A tween is an object. Save it in a variable to control it later.

play() starts or plays forward.

pause() stops at the current frame.

resume() continues in the current direction.

reverse() plays toward the beginning.

restart() starts again from the beginning.

kill() stops and removes the animation.

repeat: 2 plays two extra times; -1 loops forever.

yoyo: true plays back and forth on repeats.

timeScale(2) plays twice as fast; 0.5 is half speed.

onStart, onUpdate, onComplete run at different moments.

Ready. Press Play.

LEVEL 3

GSAP timelines

A timeline is a playlist of animations. It helps you sequence them without adding separate delays.

gsap.timeline() creates the playlist.

Add animations with .to() and .from().

"<" starts with the previous animation.

">" starts after the previous animation.

"-=0.5" overlaps by half a second; "+=1" waits one second.

A label gives a named place you can jump to.

A nested timeline is a small timeline added to another timeline.

Timelines also have controls like play() and pause().

LEVEL 4

Stagger animations

Stagger starts the same animation on a group of elements one after another.

stagger: 0.1 adds 0.1 seconds between each start.

amount: 1 spreads all starts across one second.

from: "start" starts at the first item; "end" starts at the last.

"center", "edges", and "random" change the order.

For a grid, set grid: [4, 4] and a from position.

Put a staggered tween in a timeline to sequence it with other animations.

LEVEL 5

ScrollTrigger

ScrollTrigger connects an animation to the page scroll. The plugin is loaded and registered in this project.

trigger is the element that starts watching the scroll.

start and end choose where it begins and finishes.

scrub: true ties animation progress to scroll position.

pin: true holds a section in place while it animates.

toggleActions sets what happens on enter, leave, and scroll back.

markers: true draws start/end guides while you learn.

toggleClass adds or removes a CSS class while active.

Add scrollTrigger to a timeline for scroll-based sequences.

LEVEL 6

Advanced scroll animations

Use multiple triggers to tell a story as the visitor moves through the page.

Scroll-based storytelling reveals scenes in a chosen order.

Horizontal scrolling moves a row of panels sideways while the page scrolls.

Parallax moves background and foreground at different speeds.

Pinned sections hold a scene in place during its animation.

Scroll snapping gently brings the scroll to a scene boundary.

containerAnimation lets child triggers follow a horizontal animation.

Multiple triggers can control different elements independently.

refresh() recalculates positions; invalidateOnRefresh recalculates animation values too.

LEVEL 7

Advanced GSAP tools

These helpers make animations easier to reuse, adjust, and adapt to the screen.

gsap.set() changes values immediately, without animating.

gsap.utils.clamp() keeps a number within limits.

mapRange() converts a number from one range to another.

random() makes a random value; wrap() loops through a range.

quickTo() quickly animates a value to a new target.

quickSetter() sets a value quickly without creating a tween each time.

matchMedia() runs different animation setups for different screens.

context() groups animations so you can clean them up together.

Responsive animations use media queries and refresh when their layout changes.

GSAP can animate SVG attributes like position, rotation, and path drawing.

LEVEL 8

Interactive animations

Animations can respond to the pointer, clicks, and dragging.

Mouse-follow animations use pointer position to update an element.

A custom cursor is a styled element that follows the pointer.

Hover effects animate when a pointer enters or leaves an element.

Click interactions run an animation when a button is pressed.

Draggable lets you drag an element and optionally set its bounds.

SplitText divides text into words or letters for animation.

MorphSVGPlugin smoothly changes one SVG shape into another.
